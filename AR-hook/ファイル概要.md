## 実行ファイル
- [AR-hook1.py](./AR-hook1.py)：メインプログラムです。カメラ映像とArUcoマーカーを処理し、PixhawkとのMAVLink通信、目標指令、CSV記録などを行います。
- [marker_pose_calibration.py](./marker_pose_calibration.py)：AR-hookや校正・解析ツールが共通で使う、姿勢・座標変換の関数です。
- [camera_params.npz](./camera_params.npz)：カメラの内部パラメーターと歪み係数です。マーカーの位置・姿勢を推定するときに使います。
- [marker_pose_offsets.json](./marker_pose_offsets.json)：HandとCargoのARマーカーと基準点との姿勢オフセットです。校正ツールが作成し、AR-hookが読み込みます。

## 校正・カメラ設定用
- [calibrate_marker_pose_offsets.py](./calibrate_marker_pose_offsets.py)：ARマーカーとMotive剛体との固定位置・姿勢差を、記録CSVから計算します。
- [calibrate_camera_optical_offset.py](./calibrate_camera_optical_offset.py)：カメラの光学中心と位置・姿勢の基準とのずれを校正します。設定ファイルの生成に使う補助ツールです。
- [camera-cal.py](./camera-cal.py)：チェスボードを使ったカメラ校正ツールです。カメラ映像を表示して操作します。
- [camera-cal_ssh.py](./camera-cal_ssh.py)：SSH利用時向けのカメラ校正ツールです。画面表示なしで校正します。
- [cargo_marker_pose.svg](./cargo_marker_pose.svg)：Cargoのマーカー配置を示す図です。

## 解析・送信補助
- [plot_pose_offset_comparison.py](./plot_pose_offset_comparison.py)：ARのオフセット適用前後の位置と、適用後の姿勢をMotiveと比較するグラフを作ります。
- [plot_hand_cargo_relative.py](./plot_hand_cargo_relative.py)：HandとCargoの相対位置・距離をCSVからグラフ化します。
- [send_GPS3.py](./send_GPS3.py)：Motiveの位置データをPixhawkへGPS_INPUTとして送る独立プログラムです。AR-hook本体からは自動起動されません。

## 依存ライブラリー
- [requirements.txt](./requirements.txt)：Pythonの必要ライブラリー一覧です。


## Pixhawkから受信

| MAVLinkデータ | 値 | 単位・形式 |
|---|---|---|
| `ATTITUDE` | roll・pitch・yaw | ラジアン |
| `GLOBAL_POSITION_INT` | 緯度・経度 | 度を`10⁷`倍した整数 |
|  | 相対高度 | mm（コード内で1000で割りmに変換） |
| `HEARTBEAT` | モード・アーム状態 | 数値フラグ |

## Pixhawkへ送信

| MAVLinkデータ | 値 | 単位・形式 |
|---|---|---|
| `SET_POSITION_TARGET_GLOBAL_INT` | 緯度・経度 | 度を`10⁷`倍した整数 |
|  | 相対高度 | m |
|  | yaw | ラジアン（現在は北向き`0`） |
| `MAV_CMD_NAV_TAKEOFF` | 離陸高度 | m |

## ARhook1のPixhawkへの送受信工程*
 
1. MAVLink接続 — [788行](./AR-hook1.py#L788)で接続を開き、[791行](./AR-hook1.py#L791)でPixhawkの`HEARTBEAT`を待ちます。

2. 受信頻度の要求 — [799〜803行](./AR-hook1.py#L799-L803)で、Pixhawkにメッセージ送信間隔を要求します。指定しているIDは24（GPS_RAW_INT）、33（GLOBAL_POSITION_INT）、30（ATTITUDE）で、間隔は200,000µs（5Hz）です。

3. 機体状態の受信 — [1065行](./AR-hook1.py#L1065)からの`monitor_vehicle()`が状態を監視します。[1072〜1076行](./AR-hook1.py#L1072-L1076)で`HEARTBEAT`からGuidedモードとアーム状態を確認し、[1092〜1098行](./AR-hook1.py#L1092-L1098)で姿勢を、[1099〜1123行](./AR-hook1.py#L1099-L1123)で現在位置を受信・更新します。

4. 離陸指令 — Guidedかつアーム済みを検出すると、[1080〜1084行](./AR-hook1.py#L1080-L1084)付近で約3秒後に離陸指令を送ります。送信関数は[804〜806行](./AR-hook1.py#L804-L806)で、コマンドは`MAV_CMD_NAV_TAKEOFF`です。目標高度に達した後、[1124〜1128行](./AR-hook1.py#L1124-L1128)付近で追跡目標の送信を許可します。

5. ARから目標位置を計算 — [1672行](./AR-hook1.py#L1672)以降でマーカーから位置・姿勢を取得し、[1006行](./AR-hook1.py#L1006)以降の座標変換処理などを使って目標を計算します。目標をGPS座標へ変換する処理は[1793〜1797行]((./AR-hook1.py#L1793-L1797))です。

6. Guided目標を送信 — Guided中かつ離陸後であれば、[1794〜1797行](./AR-hook1.py#L1794-L1797)で`send_setpoint()`を呼びます。送信本体は[807〜811行](./AR-hook1.py#L807-L811)で、`SET_POSITION_TARGET_GLOBAL_INT`に緯度・経度・相対高度とyawを載せています。マスクは[35行](./AR-hook1.py#L35)の`0x09F8`、yawは北向き0°固定です。
